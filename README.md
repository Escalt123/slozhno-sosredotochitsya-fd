# no focus — «Сложно сосредоточиться»

Адаптивная одностраничная статья о том, почему нам трудно концентрироваться и что с этим делать. У страницы две цветовые темы — неоновая и светлая — и переключатель между ними.

# ссылка на репозиторий 
https://github.com/Escalt123/slozhno-sosredotochitsya-fd

## Что реализовано

- **Адаптивная вёрстка по принципу mobile first** — три брейкпоинта: 375, 768 и 1024 px. Макет резиновый, между брейкпоинтами контент тянется.
- **Две цветовые темы:**
  - «Неон» — основная, тёмная;
  - «День» — светлая;
  - «Авто» — тема подстраивается под настройки системы через медиафичу `prefers-color-scheme`.
- **Переключение тем через CSS-переменные.** Все значения объявлены в `variables.css`, а файлы тем только переопределяют те, что отличаются.
- **Сетки на CSS Grid** — шапка и галерея размечены через `grid-template-areas`, секции контента перестраиваются в две и три колонки.
- **Состояния интерактивных элементов** по UI-киту: `:hover`, `:focus-visible` и активная кнопка темы.
- **Именование классов по БЭМ.**
- **Локальные шрифты** IBM Plex Mono (Regular и Bold) с `font-display: swap`.
- **Доступность:** альтернативный текст у изображений, видимый фокус для навигации с клавиатуры, декоративные элементы скрыты от скринридеров.

## Технологии

- HTML5 (семантическая разметка)
- CSS3: Grid, Flexbox, Custom Properties, медиазапросы
- БЭМ
